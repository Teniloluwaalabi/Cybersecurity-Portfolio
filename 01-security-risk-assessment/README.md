# Cybersecurity Risk Assessment – FinTrust Financial Services Ltd.

## Project Overview

This project presents a fictional cybersecurity risk assessment conducted for **FinTrust Financial Services Ltd.**, a fictional fintech organization providing online banking, mobile payments, international money transfers, digital wallets, and merchant payment solutions.

The assessment demonstrates a structured approach to identifying information security risks, evaluating their potential business impact, and recommending appropriate security controls.

> **Disclaimer:** FinTrust Financial Services Ltd. is a fictional organization created for educational and portfolio purposes. This project is not a formal security audit, penetration test, compliance assessment, or certification.

---

## Project Objectives

The objectives of this assessment were to:

* Identify critical business and information assets
* Analyze relevant cybersecurity threats
* Identify security vulnerabilities
* Assess and prioritize cybersecurity risks
* Recommend appropriate security controls
* Map security practices to recognized frameworks
* Communicate cybersecurity risks in a business-focused format

---

## Assessment Methodology

The assessment followed these key stages:

**1. Company Overview**
Understanding the organization's business operations and security objectives.

**2. Asset Inventory**
Identifying important systems, information, infrastructure, and business assets.

**3. Threat Analysis**
Identifying potential cybersecurity threats and assessing their likelihood and impact.

**4. Vulnerability Assessment**
Identifying weaknesses that could increase the organization's exposure to threats.

**5. Risk Assessment**
Calculating risk using:

**Risk = Likelihood × Impact**

Risks were categorized as Low, Medium, High, or Critical.

**6. Security Controls**
Recommending preventive, detective, and corrective controls to reduce identified risks.

**7. Compliance & Framework Mapping**
Mapping assessment activities to the **NIST Cybersecurity Framework** and considering alignment with **ISO/IEC 27001**.

**8. Executive Reporting**
Summarizing key risks, business implications, and recommended priorities for management.

---

## Key Findings

The assessment identified several significant cybersecurity risks, including:

| Risk                          | Rating   |
| ----------------------------- | -------- |
| Phishing                      | Critical |
| Credential Theft              | Critical |
| Ransomware                    | Critical |
| Customer Data Breach          | High     |
| Insider Threat                | High     |
| Unpatched Systems             | High     |
| Third-Party Vendor Compromise | High     |
| DDoS                          | High     |
| Malware Infection             | High     |
| Inadequate Backups            | High     |

The assessment highlighted the importance of strong identity and access management, employee security awareness, vulnerability management, endpoint protection, backup and recovery, monitoring, and third-party risk management.

---

## Recommended Security Controls

Key recommendations included:

* Multi-factor authentication (MFA)
* Security awareness training
* Phishing simulations
* Least-privilege access
* Regular access reviews
* Patch and vulnerability management
* Endpoint detection and response (EDR)
* Encryption and access controls
* Tested and encrypted backups
* Centralized logging and security monitoring
* Third-party security assessments
* Incident response planning

## Frameworks Referenced

### NIST Cybersecurity Framework

The assessment considered the five core NIST CSF functions:

* **Identify**
* **Protect**
* **Detect**
* **Respond**
* **Recover**

### ISO/IEC 27001

The assessment also considered relevant information security management areas including:

* Information security policies
* Access control
* Asset management
* Operations security
* Supplier relationships
* Incident management
* Business continuity
