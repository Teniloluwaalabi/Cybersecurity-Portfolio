# Security Risk Assessment

## Project Overview

This project documents a cybersecurity risk assessment conducted for a fictional financial services company.

The objective is to identify valuable assets, evaluate cybersecurity risks, assess potential business impacts, and recommend appropriate security controls based on recognized cybersecurity frameworks.

---

## Skills Demonstrated

- Risk Assessment
- Threat Identification
- Vulnerability Assessment
- Risk Analysis
- Security Controls
- Security Documentation
- Governance, Risk & Compliance (GRC)

---

## Frameworks

- NIST Cybersecurity Framework
- ISO/IEC 27001
