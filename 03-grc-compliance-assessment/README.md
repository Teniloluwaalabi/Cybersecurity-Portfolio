# GRC & Compliance Assessment – FinTrust Financial Services Ltd.

## Overview

This project demonstrates a practical Governance, Risk, and Compliance (GRC) assessment for a fictional fintech organization.

The assessment evaluates selected security controls against recognized cybersecurity and information-security frameworks, identifies gaps, assesses associated risks, and recommends remediation actions.

> **Disclaimer:** This is a fictional cybersecurity portfolio exercise. It is not a formal regulatory audit, certification assessment, or legal/compliance opinion.

---

## Objectives

The objectives of this assessment are to:

* Evaluate the organization's existing security controls
* Identify governance and compliance gaps
* Map controls to recognized security frameworks
* Assess the risks associated with identified gaps
* Recommend practical remediation actions
* Establish priorities for improving security governance
* Demonstrate GRC documentation and analysis skills

---

## Organization

**Company:** FinTrust Financial Services Ltd.

**Industry:** Financial Technology / FinTech

FinTrust provides digital financial services including online banking, mobile payments, digital wallets, international money transfers, and merchant payment solutions.

The organization handles sensitive customer and financial information and therefore requires effective governance, risk management, and security controls.

## Frameworks Referenced

The assessment uses the following frameworks as reference points:

### NIST Cybersecurity Framework

The assessment considers the five core functions:

* Identify
* Protect
* Detect
* Respond
* Recover

### ISO/IEC 27001

The assessment considers information-security management practices including:

* Information security policies
* Asset management
* Access control
* Human resource security
* Operations security
* Supplier relationships
* Incident management
* Business continuity
